Submit a Variant Assessment

Have you assessed whether a variant is eligible for a therapeutic approach? Share the assessment with the N1C Gene Registry. This form is for variant assessments; to submit a therapy development project, use the N-of-1 projects form. For questions, write to generegistry@n1collaborative.org.

The name of your group is shown next to your assessment on the registry, the way ClinVar shows each submitter. Several groups may assess the same variant.

Upload several assessments at once

Three steps: download the template, fill in one assessment per row (keep the header row as it is), then choose the file here. The same checks as the form run over every row; nothing is blocked, and a curator checks every entry by hand.

1 Download the template Excel file with one column per field, the allowed values on an Options tab, and two example rows.
2 Fill in one assessment per row: one modality and approach per row, so a variant assessed for two approaches takes two rows.
3 Choose the filled-in file below.
